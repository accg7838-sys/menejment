# Сэдэлжүүлэлт ба ажлын гүйцэтгэл

12 дэлгэцтэй, Монгол хэл дээрх статик веб танилцуулга. Интернэт, build, нэмэлт сан шаардахгүй.

`index.html` файлыг Chrome, Edge, Firefox эсвэл Safari хөтчөөр нээнэ. Хавтсыг бүхэлд нь хуулж зөөвөрлөнө.

- Дараах: →, Space, PageDown
- Өмнөх: ←, PageUp
- Эхний / сүүлийн: Home / End
- Бүтэн дэлгэц: F эсвэл ⛶ (хөтчийн дэмжлэгээс хамаарна)
- Илтгэгчийн тайлбар: N эсвэл «Тайлбар»; хаах: Escape
- URL-ийн #1–#12 нь одоогийн дэлгэцийг хадгална.

Нүүрийн хичээл, код, багш, огнооны мөрөнд шууд бичиж болно. Хөтөч зөвшөөрсөн үед тухайн төхөөрөмжид хадгална.

Танилцуулга 1600×900 суурьтай; viewport-д харьцааг хадгалан багтана. 1366×768, 1920×1080, 1280×720 проекторын хэмжээнд зориулав. Гар утасны босоо дэлгэцэд жижиг харагдах тул хэвтээ эргүүлнэ.

## Эх сурвалж ба тайлбар

Үндсэн эх: `Сэдэлжүүлэлт_ба_ажлын_гүйцэтгэл_засварласан.docx`. Даалгаварт заасан бүтцийг ашигласан; гаднаас судалгаа, тоо нэмээгүй. Арга зүйн дэлгэцийн «7 үндсэн бүтээл · Herzberg-ийн онолын суурь» гэдэг нь даалгаврын хэллэг: эх баримтын долоон бүтээлд Herzberg багтдаг, найм дахь судалгаа нэмээгүй.

Тоон үр дүнгийн доор зохиогч, он бий. ρ≈.30 нь корреляци; d=.72 нь стандартчилсан ялгаа; 13% нь Ctrip-ийн гүйцэтгэлийн өөрчлөлт. 22% нь дахин сонголтын дараах гүйцэтгэлийн давуу тал. Ахицын шат болон системийн диаграмууд тоон график биш. Байгууллагад хэрэгжүүлэх жишээ нь багийн санал.

Файлууд: `index.html`, `assets/style.css`, `assets/app.js`.

## Хийгдсэн шалгалт

Chrome-д 1366×768, 1920×1080, 1280×720 хэмжээгээр 12 слайдыг нээж, агуулга эх сурвалжийн мөртэй давхцаагүйг шалгасан. Слайд шилжилт, URL hash, refresh, илтгэгчийн тайлбарыг шалгасан. Туршилтын хөтчийн орчин fullscreen хүсэлтийг зөвшөөрөөгүй тул үүнийг баталгаажуулаагүй; шаардлагатай бол хөтчийн өөрийн бүтэн дэлгэцийн цэсийг ашиглана.


Слайд солигдоход үгс болон диаграмууд зүүн талаас ээлжлэн орж ирнэ. Хулгана дагасан хөдөлгөөн байхгүй.

Слайд шилжих үеийн parallax: арын тойрог, гарчиг, диаграм тус бүр өөр зай, хурдаар хөдөлнө. Өмнөх слайд руу буцахад чиглэл солигдоно. Хөдөлгөөн багасгах тохиргоотой үед унтарна.

## Нэг хуудасны горим

Бүх 12 хэсэг нэг урт хуудсанд харагдана. Доош гүйлгэхэд үгс, диаграм ээлжлэн гарч, арын дүрс гүйлгэлттэй parallax хөдөлгөөн хийнэ. Доод удирдлага хэсэг хооронд шилжүүлнэ; явцын зурвас гүйлгэлтийг дагана.
